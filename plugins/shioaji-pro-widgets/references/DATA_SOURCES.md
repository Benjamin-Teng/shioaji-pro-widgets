# Data Sources — 選對來源，不要重複造輪子

Widget 取資料前**照這個順序選來源**，選到第一個能回答問題的就停。
跨來源混用同一個數字（例如同時拿 Shioaji 盤中快照與 TWSE 盤後收盤價講「今天漲幅」）
是本 plugin 最常見的錯誤，會產生對不起來的數字。

## 順位

| 順位 | 來源 | 什麼時候用 | 邊界 |
| --- | --- | --- | --- |
| 1 | **Shioaji Pro 原生 MCP tools** | 使用者自己的帳務、持倉、下單、版面、指標、回測、盤中報價 | 唯一能碰到「這位使用者」的來源 |
| 2 | **Shioaji API**（Python / CLI / HTTP） | Pro 沒有對應語意工具，但需要即時或歷史行情、資券餘額、券源、排行 | 需要已登入的 session；**沒有基本面與法人資料** |
| 3 | **TWSE Open API** | 上市市場的公開盤後統計、月營收、財報 | 免驗證、授權明確；無查詢參數、整包回傳、盤後日更。見 `TWSE_OPENAPI.md` |
| 4 | **FinMind** | 三大法人、月營收、財報、股利、本益比、融資券；**Sponsor 另有券商分點與分K** | 額度與可用 dataset **依帳號等級而定，先查 `user_info`**。見 `FINMIND.md` |
| 5 | **TPEx Open API** | 只有在明確要上櫃／興櫃資料時 | **只有上櫃，沒有上市**；穩定性較差。見 `TPEX_OPENAPI.md` |

**TWSE 優先於 TPEx。** 使用者問的個股九成是上市（2330、2317 都在 TWSE），
TPEx 只在標的確定為上櫃時才用。

## 哪個問題找哪個來源

| 想要什麼 | 去哪拿 |
| --- | --- |
| 使用者持倉、損益、交割、委託 | 順位 1，**只能**是順位 1 |
| 盤中即時報價、五檔、K 棒 | 順位 1 或 2 |
| 歷史 tick / K 棒 | 順位 2 |
| 資券餘額、券源、當日排行 | 順位 2 |
| **三大法人買賣超** | **順位 4（FinMind）**——TWSE OpenAPI 沒有這個端點 |
| **券商分點進出** | 順位 4，且**需要 Sponsor 等級**；Free 等級做不到 |
| 月營收、財報（上市） | 順位 3 或 4 |
| 月營收（上櫃／興櫃） | 順位 5——**TWSE 沒有**上櫃／興櫃月營收端點（2026-09-09 實測） |
| 股利、本益比、還原股價 | 順位 4 |
| 注意股、處置股、暫停交易 | 順位 2 或 3 |
| 除權息預告 | 順位 3 |

## 已排除（查證過做不到，不要再試一次）

- **券商分點進出（免費管道）**：官方一手來源只有 TWSE `bsr.twse.com.tw/bshtm/` 與
  TPEx `brokerBS.php`，**都是互動式網頁、都有驗證碼、都沒有 API**；
  TWSE 使用條款第 6 條明文禁止未經同意的自動化擷取。
  **但這不是死路**——FinMind 的 `TaiwanStockTradingDailyReport` 在 **Sponsor 等級**
  可用（專屬端點，單次只回一天）。規劃分點類 widget 前先用 `user_info` 確認等級，
  並在 Free 等級時明說做不到，而不是改用爬蟲。
- **基金完整持股明細**：SITCA 自民國 104 年 6 月起停更完整明細，
  現在只公開「每月前十大持股」與「季度佔淨值 1% 以上」，每月第 10 個營業日更新，
  無 API，月報是 ZIP。**想看「投信在調節什麼」請改用三大法人的投信買賣超**（順位 4）。
  主動式 ETF 是例外：FinMind Sponsor 的 `TaiwanStockActiveETFHolding` 有每日持股明細與異動。
- **重大訊息、股東會**：MOPS 只有網頁互動查詢，沒有結構化出口。
  （月營收與財報有，在 TWSE OpenAPI 的 `/opendata/` 底下。）

## 硬規則

- **帳務與下單只能走順位 1。** 任何情況下都不要用公開資料推測使用者的持倉或損益。
- **一個問題只用一個來源算數字。** 需要跨來源時，明講哪個數字來自哪裡，
  並標註兩者的時間基準（盤中即時 vs 盤後日結）。
- **公開資料是日結的。** 順位 3、4、5 幾乎都是收盤後才更新；
  盤中拿它們回答「現在多少」一定是錯的。
- **來源掛掉不要猜。** 明說某個來源取不到，回傳能拿到的部分，
  不要用記憶或推估補值。
- **不要假設 FinMind 等級。** 需要付費等級 dataset 時先查 `user_info`；
  等級不足就明說這個 widget 在當前帳號做不到。
- **不要在前端直連順位 3 與 5。** 兩者的資料端點都沒有 CORS。
- Widget 不自己存快取檔。需要重複讀的資料，在同一次對話內傳遞。
