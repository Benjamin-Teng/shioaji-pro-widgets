# 月營收速讀

**痛點**：每月 10 號一堆公司公布營收，看不完，也不知道哪幾檔跟自己有關。
**回答**：給一組代號，回報各自最新月營收與月增／年增，只講數字。

## 前置

不需要任何 Shioaji Pro 能力層級，也不需要帳號或 API key——TWSE 與 TPEx Open API
免驗證。使用者沒給代號就問，不要自己挑股票或擅自擴大成全市場掃描。

## 流程

1. **先決定市場別，端點互不涵蓋**（TWSE 上沒有上櫃月營收）：
   - 上市：`GET https://openapi.twse.com.tw/v1/opendata/t187ap05_L`
   - 上櫃：`GET https://www.tpex.org.tw/openapi/v1/mopsfin_t187ap05_O`
   - 興櫃：`GET https://www.tpex.org.tw/openapi/v1/t187ap05_R`
   分不出來就**依序查上市 → 上櫃 → 興櫃**，第一個有資料的為準；三個都沒有才叫查無。
2. 兩邊**同源於 MOPS，欄位結構完全相同**，一套解析邏輯即可（見下）。
3. 端點**不吃參數**、回傳全市場整包、沒有分頁（實測上市 1085 筆、上櫃 890 筆）。
   收斂到使用者那幾檔是這個 widget 的工作。同一次對話同一端點只打一次。
4. TPEx 的必要標頭見共用檔 `references/TPEX_OPENAPI.md`，不帶會 403 或 520。

## 欄位（中文 key，兩邊一致）

`公司代號`、`公司名稱`、`產業別`、`資料年月`（民國年月，如 `"11507"` = 2026 年 7 月）、
`出表日期`（民國年 `yyyMMdd`）、`營業收入-當月營收`、`營業收入-上月營收`、
`營業收入-去年當月營收`、`營業收入-上月比較增減(%)`、`營業收入-去年同月增減(%)`、
`累計營業收入-當月累計營收`、`累計營業收入-去年累計營收`、
`累計營業收入-前期比較增減(%)`、`備註`。

**金額單位是新台幣千元**，數值是字串。增減率官方已算好，**直接用，不要自己重算**。

## 輸出

三行結論（查了幾檔、資料年月是哪個月、其中幾檔年增為正）加一張小表：
代號、名稱、當月營收、月增率、年增率。查無資料的代號單獨列出。

**一定要標資料年月**。這是月更資料，`資料年月` 通常落後當下一到兩個月
（每月約 10 號公布上個月），不要講成「本月」或「最新」。

## 不做

- **只陳述數字與變化，不解釋成因、不推論股價。**
  「營收年增 32%」可以；「營收動能強勁值得留意」「優於預期」不行。
- 不排名、不篩「營收創新高」清單，除非使用者明確要求，且仍只給事實。
- 不下單、不讀帳務、不從公開資料推測使用者持有什麼。
- 取不到就說取不到，不要用前一期數字或記憶補值。
